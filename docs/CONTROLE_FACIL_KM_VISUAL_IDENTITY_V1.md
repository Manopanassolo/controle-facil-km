# Controle Fácil KM — Identidade Visual V1

## Direção

A nova identidade deve transmitir:
- simplicidade;
- mobilidade;
- controle financeiro;
- confiança;
- uso pessoal.

A interface deixa de usar a identidade Movvant/nude atual do legado.

## Paleta V1

- Azul principal: #155EEF
- Azul escuro: #123A7A
- Azul claro: #EAF2FF
- Amarelo destaque: #FFC928
- Fundo: #F6F8FC
- Cartão: #FFFFFF
- Texto: #172033
- Texto secundário: #667085
- Sucesso: #12B76A
- Erro: #F04438

O azul é a cor estrutural. O amarelo é reservado para destaque, alertas positivos e elementos de ação.

## Logo

Conceito:
- símbolo de velocímetro/rota simplificado;
- ponto de localização integrado;
- wordmark “Controle Fácil”;
- “KM” como assinatura curta.

O logo deve funcionar em:
- fundo branco;
- fundo azul;
- ícone quadrado;
- favicon;
- launcher Android.

## Navegação

Menu principal:
1. Início
2. Nova viagem
3. Viagens
4. Despesas
5. Agenda
6. Relatórios
7. Veículos
8. Configurações

Plano/assinatura aparece no perfil/configurações, não como parte da navegação diária.

## Dashboard

Cards principais:
- KM no período
- Despesas no período
- Custo por KM
- Viagens

Ação primária:
**+ Nova viagem**

Ação secundária:
**+ Nova despesa**

## Regras de UX

- telas com uma ação primária clara;
- formulários divididos por etapas quando necessário;
- botão voltar em telas internas;
- retorno consistente para Início;
- estado offline visível, mas discreto;
- sincronização indicada por status, não por bloqueio da interface;
- nenhuma tela deve depender de terminologia empresarial.
